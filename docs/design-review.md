# 表示を見ながらの3回の見直し

## 1. 情報と文章

前案では、大きな抽象コピーの下に小さな説明が続き、Atoの画面が最初の表示範囲にほぼ入っていなかった。冒頭のコピーを削り、自己紹介を一文に短縮。Atoの用途を「QRコードで受付する順番待ちツール」と明記した。本人の発言として確認できない感想や、ポエム風の締め文を削除。

## 2. 画像と読みやすさ

本文を旧案の13〜14pxから16〜18pxへ変更。書体をBIZ UDPGothic / Hiragino Sans / Meiryoに変更。2枚のスクリーンショットを並べた案を確認したところ、Atoのトップ画面内の抽象的なコピーが目立っていた。受付作成画面を主表示とする切り替え式に修正。モバイルは商品名→実画面→説明の順にした。

## 3. 全体の重複と操作

PC・390px・320pxで実表示を確認。実績紹介は用途、最大約10組、2日間の運用結果に限定。名前の説明は造語のきっかけまでに短縮。画像切り替えをクリックとEnterキーで確認し、320pxのヘッダーの不自然な折り返しを修正。共有画像の旧コピーも置き換えた。

## 素材上の制約

リポジトリ内にMFT会場の写真や開発者の写真はない。手元にある実画面2枚を使用し、イベント写真や利用者の声は創作していない。実際のブース写真が加わると、実績紹介をさらに具体的にできる。
